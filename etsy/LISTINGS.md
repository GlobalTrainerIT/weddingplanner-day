# Vow printables on Etsy: listing copy

Files: `etsy/out/` (rebuild with `node scripts/build-etsy.mjs`).
Upload **both** PDFs (Letter + A4) to each listing as the digital files, and
the matching `images/<listing>-N.jpg` in order as the photos (photo 1 is the
thumbnail).

Shared settings for every listing:
- Type: **Digital files** · Who made it: **I did** · What is it: **A finished product** · When made: **2020–2026**
- Category: Paper & Party Supplies → Paper → Calendars & Planners (bundle / checklist / budget / timeline); Weddings → Guest list (RSVP set, if offered)
- Renewal: automatic · Quantity: 999
- Attributes: Occasion **Wedding** · Orientation **Portrait** · Digital file type **PDF**

Etsy policy note: the photos don't mention the app. The last page of each PDF
is a thank-you page that names weddingplanner.day. Etsy generally allows that
inside a file, but if they ever flag it, remove `closing` from `PRODUCTS` in
the script and rebuild.
